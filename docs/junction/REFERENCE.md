# Reference

| Attribute    | Format                                                                 | Example / Possible Values  |
|--------------|------------------------------------------------------------------------|----------------------------|
| Phone Number | [E.164 (international) format](https://en.wikipedia.org/wiki/E.164)    | `+442085664503`            |
| County Code  | [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) | `NL`                       |
| Date Time    | [RFC 3339](https://datatracker.ietf.org/doc/html/rfc3339#section-5)    | `2022-05-12T10:17:28.343Z` |
| Title        | string                                                                 | `mr` `ms`, `mrs` or `miss` |
| Gender       | string                                                                 | `male` or `female`         |
