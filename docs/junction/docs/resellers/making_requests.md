# Making Requests

Here are the building blocks to set up your first request.

## Authentication

You'll need to include an access token in every request you make to the API except the `/users/tokens` endpoint.

To get an access token see the `/users/tokens` endpoint.

Send your access token in the Authorization request header using the "Bearer" authentication scheme:

`Authorization: Bearer <YOUR_ACCESS_TOKEN>`

## MIME types

All responses from the API follow the [JSON:API](https://jsonapi.org/) standard.
An Accept header is required with every request:

`Accept: application/vnd.api+json`

All request bodies sent to the API should be in JSON format.
A Content-Type header is required whenever you're sending a request body (i.e. for POST and PUT requests):

`Content-Type: application/vnd.api+json`

## Session Token

Some endpoints require a session token.
This token should be a random 32-character long string generated by you, and should be the same throughout a booking flow, but different for each new booking flow.


## Polling

Most endpoints are asynchronous, which means that after `POST`ing a request (for example a trip search)
you have to regularly poll for the results until the status of the search is marked as completed.
