# Glossary

| Term     | Definition                                                             |
|----------|------------------------------------------------------------------------|
| Client   | Someone who consumes Junction's Client API.                            |
| Leg      | A direct journey between two points on the same vehicle.               |
| Order    | An offer that has been, or is requested to be, purchased.              |
| Place    | An identifiable point with additional metadata like name, country etc. |
| Point    | A pair of coordinates.                                                 |
| Provider | Someone who provides Junction with content (offers or schedules).      |
| Segment  | A collection of one or multiple legs on the same vehicle.              |
| Trip     | A collection of one or multiple segments.                              |
